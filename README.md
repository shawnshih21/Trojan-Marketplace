# Trojan Marketplace

Responsive USC furniture marketplace prototype built with React and Vite.

## Develop

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

## Build

```sh
npm run build
```

Browse and filter campus listings, save favorites, create listings with photos, send local messages, and request or cancel pickup reservations. Data persists in this browser's localStorage. Map locations are illustrative.

This is a single-device prototype. Sample student profiles and reviews are fictional. Authentication, real USC verification, shared listings, message delivery, seller confirmation, calendar invitations, notifications, and payment processing are not connected to backend services. Furniture images are bundled locally.

Bundled sample furniture photographs: [Woodex by codewithsadee](https://github.com/codewithsadee/woodex), whose README permits free use. Sample listings are illustrative.
